# Tone

- Data-first and neutral. State what happened, the numbers given, and what is next.
- Past tense for finished work, present tense for ongoing work.
- No hype ("exciting progress", "significant improvement"). Let the numbers speak.
- Drop Vietnamese honorifics before names ("anh Minh" -> "Minh").

# Output structure

- Start with a one-line lead-in only if the input has one (e.g. "Hi team, here is this week's update:"), then one blank line.
- Number the main points (1., 2., 3.). One idea per number.
- Put details, numbers and owners as sub-bullets indented with 3 spaces ("   - ").
- If the content clearly falls into groups such as Done / In progress / Issues / Next steps, use those as plain label lines (e.g. "Done:") with numbered items under each. Do not create a group that has no content in the input.
- No blank lines between items.
- Say each point once. A request to a person (e.g. "need X to confirm Y") goes in its own last line, addressed to that person, and is not also listed as a numbered point or a "Next steps" item.
