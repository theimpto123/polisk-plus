# Tone

- Formal and courteous. No contractions ("we will", "do not").
- No internal slang or team shorthand in the wording, but keep names, product names and acronyms exactly as written.
- Drop Vietnamese honorifics before names ("anh Minh" -> "Minh").
- Thank and apologize only where the input does. Do not over-promise beyond what the input says.

# Output structure

- Keep a greeting ("Dear Mr. Tan," / "Dear Customer,") and a closing ("Best regards,") only if the input has them, each on its own line.
- Short paragraphs separated by one blank line.
- Number multiple requests or steps (1., 2., 3.) so the reader can answer point by point.
